# 08｜关系网络与群像自生长

## 一、为什么关系先于大量剧情

稳定的长篇事件来自关系中的未结事项：

- 欠债未还。
- 恩情无法等价偿还。
- 共同秘密。
- 权力不对称。
- 爱与目标冲突。
- 利益一致但价值观相反。
- 一方误解另一方的动机。
- 组织身份与私人感情冲突。

只要这些边存在，环境压力一来，剧情会自然生成。

## 二、关系边的完整字段

每条重要关系记录：

| 字段 | 含义 |
|---|---|
| REL-ID | 唯一编号 |
| 双方 | 角色或势力 ID |
| 表面关系 | 师徒、同僚、敌人、亲属、合作等 |
| 真实交换 | 资源、保护、认可、情报、身份、情感 |
| 权力差 | 谁更能决定结果 |
| 信息差 | 谁知道对方不知道的事实 |
| 情感张力 | 敬、爱、惧、妒、愧、欲、怨等 |
| 未清债务 | 恩、仇、承诺、合同 |
| 当前共同目标 | 为什么暂时同行 |
| 根本冲突 | 为什么终究可能分裂 |
| 破裂触发 | 哪个事件会越线 |
| 修复条件 | 需要证据、代价还是选择 |
| 终局形态 | 和解、决裂、牺牲、共治、陌路等 |

## 三、关系不是静态标签，而是状态机

典型阶段：

```text
接触 → 试探 → 交换 → 建立信用 → 产生债务 → 权力反转
→ 误解/背叛/价值冲突 → 选择 → 结算 → 残余影响
```

不必每条关系走全程，但重要关系必须有变化点。

## 四、配角之间的横向网络

为避免所有人只围绕主角：

- 每名 S/A 级角色至少设计两条非主角关系。
- 至少 30% 的重要冲突在主角介入前已存在。
- 至少一条副线可在主角缺席时推进并改变主线条件。
- 反派阵营内部有合作、竞争、亲情或债务，不是同一口径工具人。

数字可随规模调整，但原则不可省略。

## 五、关系回路

比单条关系更有生产力的是三角或四角回路：

```text
A 欠 B 的命
B 必须维护 C 的合法性
C 掌握 A 的罪证
```

一个事件会同时改变三条边，产生连锁反应。设计时至少建立：

- 主角阵营内一条利益回路。
- 对手阵营内一条权力回路。
- 跨阵营一条秘密或债务回路。
- 感情线与主线共享一条价值冲突，而非完全平行。

## 六、关系货币

关系中可交换的不止金钱：

- 信息。
- 信誉。
- 保护。
- 进入资格。
- 见证。
- 沉默。
- 公开支持。
- 情绪照顾。
- 血缘承认。
- 未来承诺。

明确关系货币，能让对话和事件具有真实权力感。

## 七、恩公、债主与复杂互惠

“恩人”不是自动忠诚，“债主”也不一定是敌人。可设计：

- 恩情无法偿还，反而造成控制。
- 债主比恩人更尊重规则。
- 受恩者不愿永远低一头。
- 同一件事对一方是救命，对另一方是夺走选择。
- 还债方式伤害第三人。

这类关系天然包含感激、羞耻、权力与自由的冲突，适合长期发展。

## 八、关系与事件双向追踪

每个重大事件标记：

- 改变了哪些 `REL-ID`。
- 权力差如何变化。
- 新增或偿还了何种债务。
- 哪个秘密被共享或暴露。
- 下一次关系决策的触发条件。

每条核心关系也应指向其建立、转折和结算事件。

## 九、关系毒点检查

- 重要女性或男性角色是否只作为奖励或嫉妒工具。
- 角色是否被迫原谅不可接受行为，只因作者要维持队伍。
- 背叛是否有足够铺垫、利益与心理链。
- 冲突是否依赖所有人拒绝正常沟通。
- 主角是否不断索取忠诚，却从不承担关系代价。
- 配角是否一旦恋爱就失去事业与目标。
- 权力不对等关系是否被浪漫化而无后果。

## 十、图谱表达

默认同时保留两种表达：

1. **关系边表**：完整、可审计。
2. **Mermaid 图**：快速观察中心度、孤立节点和派系。

图是索引，不替代表格。关系复杂时按世界、卷次或势力拆图，避免一张“蜘蛛网”不可读。
