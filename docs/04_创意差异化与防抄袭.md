# 04｜创意差异化与防抄袭

## 一、通用母题可以复用，独特实现必须重做

“重生、轮回、复制、系统、学院、宗门、末世、破案、契约婚姻”等本身通常属于通用母题。风险来自多个层面同时高度相似：

- 相同起点。
- 相同能力机制。
- 相同人物功能。
- 相同关系顺序。
- 相同关键场景。
- 相同谜底与终局。

单纯改名、改地图或把“剑”换成“枪”不是原创重构。

## 二、六层相似性审计

| 层级 | 检查内容 | 高风险信号 |
|---|---|---|
| L1 词汇 | 专名、口号、标志性意象 | 可搜索到明显一一对应 |
| L2 前提 | 主角身份、异常起点、核心任务 | 一句话梗概几乎相同 |
| L3 机制 | 金手指、代价、升级、资源循环 | 功能与解锁顺序一致 |
| L4 关系 | 导师、宿敌、恋人、组织关系 | 角色可逐个映射 |
| L5 结构 | 卷级转折、揭秘顺序、高潮 | 事件序列高度同构 |
| L6 表达 | 句法、比喻、对白、气质 | 能识别单一作者声纹 |

L1 可通过重命名解决；L3—L5 必须结构性重做；L6 必须改为多源高层声纹。

## 三、差异化至少来自三条独立轴

可选轴：

1. **代价轴**：使用优势会损失什么，不使用又会失去什么？
2. **信息轴**：谁知道真相，知识如何验证，误判如何形成？
3. **社会轴**：能力改变了市场、法律、阶层和组织行为吗？
4. **关系轴**：核心关系是债务、合作、亲缘、竞争、信仰还是互相利用？
5. **成长轴**：升级依赖积累、选择、理解、牺牲、网络或制度？
6. **终局轴**：最终问题是打败敌人、改变规则、承担责任、放弃执念还是重构世界？
7. **叙事轴**：线性、档案、多视角、倒叙、周期、双时空等。

三条轴必须彼此独立；“换三个名词”不算三条轴。

## 四、四级转换法

对每个参考点写出：

```markdown
- 表层元素：范例中具体出现了什么。
- 叙事机制：它为读者制造了什么体验。
- 抽象原则：脱离题材后仍成立的规律。
- 原创实现：本项目用不同规则、关系、代价和结果实现。
```

例：

```markdown
表层元素：神秘前辈留下多处遗产。
叙事机制：跨卷长期承诺 + 身份认知递进 + 延迟回报。
抽象原则：让过去的行动持续塑造当前选择，但每次兑现都改变责任。
原创实现：遗产不只含资源，还含敌对债权、制度漏洞、被误解的盟友和必须偿还的公共义务；获取顺序由角色选择而非地图等级决定。
```

## 五、最近似作品压力测试

选择 3—5 部最接近作品，回答：

- 不使用双方专名时，两部作品的一句话梗概是否仍像同一本？
- 主角能力是否可以不改规则直接互换？
- 主要角色是否能一一替换？
- 前三卷的关键转折是否顺序一致？
- 最著名的三个场景是否有对应版本？
- 终极谜底是否只是措辞不同？

若三项以上为“是”，需要重构，不应靠声明“只是致敬”通过。

## 六、原创重构策略

### 1. 改原因，不只改结果

同样是“身份被低估”，可以改变：评价系统为何错误、谁受益、主角为何不能立即证明、证明后谁损失。

### 2. 改关系拓扑

把单线“主角—导师—反派”改为多方债务与信息差网络。事件会因此自然变化。

### 3. 改资源闭环

能力若能复制资源，就必须问：原料从何而来、复制品如何鉴别、市场如何反应、垄断者如何反制、暴露会带来什么制度后果。

### 4. 改终局问题

即使前期类型体验相似，终局价值选择不同也能形成独特作品。但不能把独特性全部推迟到最后。

### 5. 改角色的错误信念

相同外部目标，由不同内在创伤与错误信念驱动，会产生完全不同的选择路径。

## 七、文风防模仿

不以“像某位作者”为验收。改用参数组合：

- 宏大尺度 + 克制情绪。
- 短动作句 + 中等信息密度。
- 少比喻但意象贯穿。
- 对话含权力差，不解释已知信息。

至少从三种来源提炼共同技法，再加入本项目自有语义场与禁用项。

## 八、原创性报告的结论等级

- `低风险`：只共享通用母题，关键机制和结构不同。
- `中风险`：某一层明显接近，已提出可执行重构。
- `高风险`：角色、机制或结构可一一对应，必须先改再继续细纲。
- `未知`：参考材料不足，不能假装安全。

原创性审计不是法律意见；涉及出版或商业纠纷时应由专业人士进一步评估。
