# 05｜世界观、规则、资源与环境

## 一、世界观的最小闭环

一个可运行的世界至少需要回答：

1. 人们靠什么生存与变强？
2. 什么东西真正稀缺？
3. 谁控制稀缺物的生产、分配与解释权？
4. 规则如何被执行，谁能例外，例外的代价是什么？
5. 普通人怎样理解世界，精英又知道哪些不同真相？
6. 死亡、疾病、贫穷、犯罪、战争、迁徙和教育如何发生？
7. 不同地区或世界为何形成不同制度与欲望？

只回答“有多少层世界、多少种族、多少境界”不构成闭环。

## 二、从环境推导欲望

环境不是背景板。对每个世界层级建立：

| 维度 | 问题 |
|---|---|
| 生存 | 最常见的死亡方式是什么？谁最安全？ |
| 寿命 | 人均寿命、健康寿命、延寿门槛如何？ |
| 资源 | 关键资源可再生吗？产地、运输、损耗、替代品是什么？ |
| 信息 | 知识如何保存、验证、传播、审查？ |
| 流动 | 人能否跨地区、阶层、身份、世界？ |
| 暴力 | 谁拥有合法暴力？私人武力怎样被限制？ |
| 家庭 | 继承、婚姻、血缘、抚养和繁衍如何受规则影响？ |
| 地位 | 名望、血统、财富、功勋、能力何者更重要？ |
| 信仰 | 人们如何解释苦难、死亡与宇宙秩序？ |

然后推导当地人的主流欲望。例如资源富足但寿命极短的世界，地位竞争、记忆保存和后代继承可能比财富积累更重要。

## 三、核心欲望与阶段性欲望

角色的核心欲望可以长期稳定，但表现形式随环境变化：

```text
核心欲望：不再被任何人抛弃
凡俗环境：积攒金钱、建立家庭、获得稳定身份
高危环境：控制信息、建立可靠盟约、追求长寿
高阶环境：掌握规则、消除不可控因果、让关系跨越时间保存
```

设计时分别记录：

- `Core Desire`：跨世界不变的深层需求。
- `Stage Goal`：当前环境中的可见目标。
- `Proxy Goal`：角色误以为可以满足核心欲望的替代目标。
- `Awakening`：何时发现替代目标无效。

## 四、规则卡的七项内容

每条重要规则包含：

1. **陈述**：一句话说清规则。
2. **适用域**：对谁、何时、何地有效。
3. **边界**：何种条件下失效或变化。
4. **成本**：遵守、利用、绕过分别付出什么。
5. **验证**：世界中的人如何知道它是真的。
6. **执行者**：自然规律、组织、契约、神明、算法或社会共识。
7. **三重后果**：个人、制度、关系/伦理。

示例：

```markdown
RULE-004｜任何跨界传送都会留下可追踪的“回声”七日。
- 个人后果：逃亡者不能连续使用传送摆脱追踪。
- 制度后果：大势力垄断回声检测，形成边境税和通缉体系。
- 关系后果：帮助他人传送等于把自己暴露在同一追踪链中。
```

## 五、资源经济

每种关键资源都要设计完整循环：

```text
产生 → 采集 → 加工 → 运输 → 储存 → 交易 → 消耗 → 废弃/回收 → 替代
```

并回答：

- 谁拥有产地？
- 谁拥有技术？
- 谁制定价格与真伪标准？
- 走私为何存在？
- 战争时哪一步最脆弱？
- 主角的优势会破坏哪个环节？
- 市场和统治者会如何反应？

金手指若能无限复制高价值资源而世界毫无反应，世界观将迅速失真。

## 六、资源稀缺的类型

- **绝对稀缺**：总量有限。
- **时间稀缺**：必须在窗口内获取。
- **地点稀缺**：只存在于特定区域。
- **知识稀缺**：知道方法的人少。
- **资格稀缺**：资源有，但只有少数身份可用。
- **信任稀缺**：交易必须依赖可靠关系。
- **注意力稀缺**：强者、机构或公众只能支持少数对象。
- **合法性稀缺**：有能力不等于被承认。

不同稀缺类型会生成不同剧情，不要把一切都写成“数量不够”。

## 七、多世界与尺度升级

每升一层世界，至少改变五项：

1. 常态危险。
2. 核心资源。
3. 主流制度。
4. 人的时间尺度。
5. 合法暴力边界。
6. 信息可靠性。
7. 主角过去优势的有效性。
8. 主要欲望与恐惧。

高层世界不能只是“山更大、城更大、强者更多”。它应拥有不同的社会组织、因果成本与伦理问题。

## 八、科学、神秘与可解释性

作品可以选择：

- 完全可解释的硬规则。
- 局部可解释、终极未知。
- 神话性规则，以仪式和象征稳定运行。

关键不是全部科学化，而是内部一致。若使用现代天文学、物理、信息论等类比，应区分：

- 真实科学事实。
- 世界内角色的解释模型。
- 作者设定的超自然规则。

不要把类比当证明，也不要用科学词汇掩盖任意魔法。

## 九、设定削减测试

每完成一轮世界观，执行：

- 删除不影响任何剧情的专名。
- 合并功能相同的资源与组织。
- 将纯说明改为冲突中的可见后果。
- 检查核心规则是否被主角方便地绕过而无人反应。
- 检查普通人是否有生活逻辑，而非所有人都围绕升级。
