# 16｜书名、简介、标签与商业包装

## 一、先研究再命名

平台书名规律变化快。生成候选前必须实时扫榜，按目标平台、分类、时间段记录：

- 常见长度。
- 句式结构。
- 高频但过饱和的词。
- 是否偏身份、机制、反差、问题、行动或结果。
- 热门书名与正文承诺是否一致。

用户若规定 12—13 字等长度，作为硬约束执行；否则不要把某一时期规则永久化。

## 二、书名的五项任务

1. 让目标读者识别题材。
2. 呈现核心异常或冲突。
3. 形成记忆点。
4. 避免与近似作品混淆。
5. 能承受百万字后期，不因前期梗失效。

## 三、书名结构库

只作为抽象结构，不直接套词：

- 身份 + 异常机制。
- 困境 + 反常解法。
- 行动宣言 + 结果反差。
- 世界规则 + 主角例外。
- 关系身份 + 核心冲突。
- 问句/否定句 + 题材承诺。
- 核心物/能力 + 使用后果。

每轮至少生成 20 个，再筛到 5—8 个，不要只给三个近义改写。

## 四、书名评分

| 维度 | 权重参考 |
|---|---:|
| 题材识别 | 20 |
| 核心卖点 | 25 |
| 新鲜度 | 20 |
| 易记易读 | 15 |
| 长期适配 | 10 |
| 搜索与混淆风险 | 10 |

评分必须说明理由。高分不能覆盖明显撞名或错误承诺。

## 五、简介的四段功能

可按平台缩短，不必机械分段：

1. **处境**：主角是谁，当前为何危险或受限。
2. **异常**：核心机制或世界反常之处。
3. **行动与代价**：主角将如何做，不做会怎样。
4. **更大承诺**：关系、谜题、世界或终局问题。

简介应写故事发动机，不是世界百科或形容词宣言。

## 六、简介常见失败

- 只说世界宏大，没有人和目标。
- 只列金手指功能，没有冲突和代价。
- 用十个专名阻挡理解。
- 所有句子都是反问与豪言。
- 把终极谜底解释完，或完全不暴露核心卖点。
- 与第一章不一致。
- 模仿热门简介的句法和梗。

## 七、一句话卖点

格式不是唯一，但必须包含：

```text
特定主角 + 异常处境/优势 + 核心行动 + 主要代价或反差
```

例如抽象形式：

> 一个被官方能力系统判定为无资格的人，能修复所有被丢弃的旧技术；他每修复一件，就更接近证明整个制度建立在一次被故意遗忘的灾难上。

重点是因果与承诺，而非堆标签。

## 八、标签与营销语

- 标签用于匹配读者，不应把所有可能元素都加上。
- 主标签 2—4 个，副标签说明体验。
- 营销语提炼可复述句，但不得承诺正文不存在的关系或爽点。
- 作品卖点应有“公共版本”和“深层版本”：前者易懂，后者支撑长期。

## 九、候选简介测试

对每版进行：

- 10 秒复述测试。
- 与前三章对照。
- 核心读者/轻度读者/老读者模拟。
- 最近似作品混淆测试。
- 删除专名后是否仍有独特机制。
- 是否留下明确可等待的问题。

## 十、最终交付

至少提供：

- 20—30 个原始书名候选。
- 8 个精筛候选及评分。
- 3—5 个不同策略的简介版本。
- 一句话卖点、50 字、100 字、平台长度版。
- 标签组合。
- 撞名与同质化风险说明。
- 推荐方案与备选方案，不宣称唯一正确。
