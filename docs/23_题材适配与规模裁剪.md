# 23｜题材适配与规模裁剪

## 一、通用 Skill 不等于所有项目都填满所有表

本 Skill 提供完整能力上限，不要求每部作品机械使用全部模块。正确做法是：

- 硬约束与状态管理永远保留。
- 与核心冲突直接相关的模块做深。
- 无关模块标记 `N/A + 理由`，而不是为了“完整”强行造设定。
- 篇幅越短，越应合并角色、势力、谜题和世界层级。

## 二、题材适配参数

先定义：

| 参数 | 可能取值 |
|---|---|
| 主驱动 | 成长 / 谜题 / 关系 / 建设 / 权力 / 探索 / 生存 |
| 世界开放度 | 封闭 / 逐层开放 / 多地图 / 多时空 |
| 规则硬度 | 硬规则 / 半硬 / 神话性 |
| 叙事规模 | 单城 / 国家 / 星球 / 多世界 |
| 视角 | 单视角 / 多视角 / 群像 / 档案式 |
| 情绪基调 | 明快 / 冷峻 / 温暖 / 黑色幽默 / 悲壮 |
| 商业节奏 | 快回报 / 中速积累 / 慢热高密度 |

这些参数决定哪些模板需要展开。

## 三、题材侧重点

### 成长升级类

重点：成长质变、资源经济、极境、地图迁移、长期回报变体。

风险：数值膨胀、换皮循环、能力万能。

### 悬疑推理类

重点：信息矩阵、公平线索、嫌疑关系、证据链、真相后的行动后果。

风险：作者藏关键事实、角色为谜底降智。

### 言情/关系驱动类

重点：独立欲望、权力边界、关系状态机、事业线、选择与承诺。

风险：误会水篇、角色卡片化、控制被浪漫化。

### 权谋历史类

重点：制度、合法性、资源、派系、信息延迟、普通人后果。

风险：全员阴谋家、权力只有名头、现代观念无环境来源。

### 科幻/奇幻探索类

重点：规则验证、尺度变化、科学事实与世界模型区分、未知的阶段性回报。

风险：术语替代因果、宏大但无人、终极谜底空泛。

### 都市职业类

重点：职业流程、利益相关者、信誉、法律、现实时间成本、关系网络。

风险：行业悬浮、万能人脉、财富数字无生活后果。

## 四、篇幅裁剪

### 10—30 万字

- 1 个核心世界。
- 1 条主冲突 + 1—2 条关系线。
- S/A 级角色控制在必要范围。
- 全书直接做到章级，无需过多远端模块。

### 50—150 万字

- 3—6 个卷级状态迁移。
- 2—4 个重要势力。
- 核心关系回路与长期谜题。
- 当前卷章级、近端场景级。

### 200 万字以上

- 多分辨率规划。
- 世界与欲望迁移。
- 旧角色跨地图再利用。
- 伏笔负债与角色规模控制。
- 固定滚动重规划门。

## 五、模板裁剪规则

每个字段可标记：

- `REQUIRED`：本项目必须填写。
- `OPTIONAL`：有证据需要时填写。
- `N/A`：不适用，并说明理由。
- `DEFERRED`：后续阶段填写，注明触发条件。

禁止为了表格齐全制造无用角色、规则或势力。

## 六、题材混合

混合题材必须区分：

- 主承诺：读者首先为什么来。
- 次承诺：为主承诺增加变化。
- 调味元素：提供气质，不占主结构。

例如“修仙 + 悬疑”必须决定是成长故事用谜题推进，还是谜题故事使用修仙规则。两者同时争主位会导致节奏和回报冲突。

## 七、适配验收

- 目标读者能在十秒内识别主承诺。
- 模板数量与篇幅相称。
- 关键模块做深，无关模块不凑数。
- 混合题材的回报窗口不互相拖延。
- 题材惯例被理解为功能，而非必须复制的外壳。
