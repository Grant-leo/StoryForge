# 18｜独立审计与迭代闭环

## 一、为什么一次自审不可信

生成者天然倾向维护自己的方案，会忽略：

- 已被解释顺畅但读者看不到的因果。
- 设定复杂带来的自我满足。
- 与参考作品过近的结构。
- 主角方便、世界失真的规则。
- 配角功能化和感情线物化。
- 长篇后期的重复与规模崩坏。

因此至少三轮独立视角审计，且审一轮、改一轮。

## 二、问题等级

| 等级 | 定义 | 处理 |
|---|---|---|
| P0 | 致命：抄袭高风险、主线不成立、硬约束违背 | 必须修复后才能继续 |
| P1 | 重大：留存、角色、规则或结构明显受损 | 本轮修复或用户豁免 |
| P2 | 中等：会降低质量但不阻断 | 排期修复 |
| P3 | 轻微：措辞、局部重复、格式 | 批量处理 |

## 三、每个问题必须有证据

标准格式：

```markdown
- ISSUE-017｜P1｜关系网过度主角中心化
- 证据：CHAR-004、CHAR-007、CHAR-009 的所有 REL 均连接 CHAR-001；卷二副线在主角离场后停止。
- 影响：群像失真，新地图需要不断引入新工具人。
- 修复：为三人建立两条互相冲突的非主角债务边，并让其中一条在卷二中点先于主线爆发。
- 验收：关系边表新增 REL；卷纲能定位关系建立与转折事件。
```

“人物不够立体”不是合格问题。

## 四、最低三轮审计

### 第一轮：逻辑、规则与可执行性

检查：

- 硬约束遗漏。
- 世界规则自相矛盾。
- 资源无来源或无限。
- 时间、距离、年龄、能力错位。
- 主线依赖巧合。
- 章纲无法转成场景。
- 伏笔无回收窗口。

### 第二轮：商业、留存与长期连载

检查：

- 书名简介与正文承诺错配。
- 前三十章回报太晚。
- 主角被动。
- 爽点重复。
- 每卷换皮。
- 金手指过强导致没有压力。
- 地图升级只放大数字。
- 更新所需角色和场景成本是否可持续。

### 第三轮：人物、情绪、文学与原创性

检查：

- 角色标签化。
- 配角只围绕主角。
- 反派降智。
- 感情线工具化。
- 情绪由旁白宣布。
- 反转只靠隐藏信息。
- 与参考作品角色/结构一一对应。
- 风格过度模仿单一作者。

## 五、专项审计

### 原创性红队

使用六层相似性表，对最近似作品主动寻找对应，不从“我已经改过”出发。

### 读者模拟

模拟：

- 核心读者：是否迅速获得承诺。
- 轻度读者：专名和信息是否过载。
- 老读者：套路是否可预测，反派是否合理。

### 设定经济学

检查资源循环、复制/制造能力、市场反应、组织反制和运输瓶颈。

### 关系伦理

检查权力不对等、同意、承诺、背叛、物化、无代价占有。

### 主题一致性

检查作品最终说的价值是否与角色选择一致，而非只由旁白宣告。

## 六、审一轮改一轮

禁止先积累五十份审计意见再一次性大改。标准闭环：

1. 冻结待审快照。
2. 独立审计。
3. 协调器去重、分级。
4. 修订代理逐条打补丁。
5. 差异审查：是否误伤其他规则或灵感。
6. 更新事实台账和变更日志。
7. 生成新快照，交给下一独立审计者。

## 七、修订优先级

按杠杆排序：

1. 核心承诺与终局。
2. 世界底层规则。
3. 主角欲望与关键关系。
4. 卷级结构。
5. 开篇与回报。
6. 局部场景。
7. 措辞与格式。

不要先润色一个根本不成立的剧情。

## 八、回归检查

每次重大修订后检查：

- 是否违反用户硬约束。
- 是否造成新时间线冲突。
- 是否让某角色失去独立动机。
- 是否破坏已安排伏笔。
- 是否令金手指能力边界变化。
- 是否影响标题简介承诺。
- 是否需迁移废案或更新关系图。

## 九、停止条件

必须同时满足：

- 至少三轮审计。
- 所有 P0 关闭。
- 连续两轮无新增 P0/P1。
- 已知 P1 均修复或获得用户书面豁免。
- 验证脚本通过。
- 总评分达到项目目标，且无一票否决。

若仍有 P2/P3，列入后续计划，不声称“找不出任何问题”。真正的停止依据是没有新增重大问题，而不是不存在任何可改进处。

## 十、审计结果不等于创作真理

审计意见必须区分：

- 事实错误。
- 因果漏洞。
- 读者风险。
- 审美偏好。

多个审计者意见不一致时，不用票数简单决定；检查哪一意见更符合用户承诺、目标读者和世界规则。
