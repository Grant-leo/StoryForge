# 06｜力量成长、非对称优势与代价

## 一、成长系统的三重功能

一个好的成长系统同时承担：

1. **能力进展**：主角能解决更难的问题。
2. **社会进展**：身份、权力、责任与敌人发生变化。
3. **认知进展**：对世界真相与自我目标的理解改变。

若只有战力数字上升，升级会很快失去意义。

## 二、境界或阶段卡

每一阶段至少说明：

- 核心变化：能力形态发生什么质变。
- 可观测表现：普通人和同阶如何识别。
- 社会位置：能进入哪些组织、承担哪些职责。
- 资源门槛：需要什么，为什么稀缺。
- 训练与理解：是否只靠资源堆积。
- 失败方式：受伤、失控、误入歧路、永久代价。
- 反制方法：同阶与弱者如何对抗。
- 越级边界：在什么条件下可越级，不能越多少。
- 极境标准：为何万古罕见，证据是什么。
- 剧情意义：达到后旧问题如何变化，新问题如何出现。

## 三、“每境界最强”如何不变成无敌文

可以保留同境极强，但必须把压力从单一战力扩展到：

- 多目标冲突：救人、保密、取证、守城不能同时完成。
- 制度压力：杀得赢，不等于杀得起。
- 信息压力：不知道敌人、规则或代价。
- 时间压力：胜利太慢仍会失败。
- 资源压力：强招只能使用有限次数。
- 关系压力：敌人利用债务、身份、承诺与舆论。
- 因果压力：赢一战会改变更大的联盟结构。

越级战斗应是优势、准备、环境与代价的组合，而非固定跨越多个大层级。

## 四、非对称优势卡

无论叫金手指、天赋、科技、遗产、系统或特殊身份，都必须记录：

| 项 | 内容 |
|---|---|
| 核心功能 | 最简能力陈述 |
| 初始能力 | 第一阶段实际可用功能 |
| 解锁条件 | 境界、认知、资源、关系、选择或代价 |
| 成本 | 能量、材料、时间、记忆、风险、债务 |
| 限制 | 数量、距离、对象、精度、冷却、权限 |
| 失败状态 | 不能使用、误用、被反制时会怎样 |
| 暴露风险 | 谁能察觉，察觉后会做什么 |
| 世界影响 | 对市场、组织、法律和战争的冲击 |
| 对手反制 | 技术、规则、舆论、诱饵、资源封锁 |
| 叙事功能 | 本阶段制造什么爽点和难题 |

## 五、强大能力的保密逻辑

“别人看不穿”不能只靠一句屏蔽。需要：

- 可见结果是否仍会暴露异常？
- 主角如何解释资源来源与成长速度？
- 盟友为何不怀疑？
- 敌人是否能通过统计、供应链、战斗痕迹推断？
- 隐瞒是否迫使主角放弃某些最优解？

保密本身应成为策略与关系冲突，而不是作者免检证。

## 六、万能能力的拆分

若核心能力能“复制、强化、升级、推演、隐藏”等多项功能，不要一次开放。建立能力树：

```text
底层原理
├── 功能 A：稳定、低风险、低收益
├── 功能 B：高收益、需要稀缺材料
├── 功能 C：高阶解锁、会暴露痕迹
└── 功能 D：终局能力、改变世界规则
```

每次解锁必须满足：

- 解决一个旧问题。
- 制造一个新问题。
- 改变主角策略。
- 不能让此前的关系与努力全部失去价值。

## 七、资源匮乏与强能力的互动

资源匮乏世界中，强大复制/制造能力的真正戏剧性不只在“主角发财”，还在：

- 真伪与来源审查。
- 价格体系崩溃。
- 既得利益者围剿或招安。
- 资源扩张导致新的瓶颈：运输、人才、信任、保护。
- 主角是否公开技术以救人，还是保密自保。
- 复制品是否复制历史、身份、因果或只复制物质。

## 八、极境与唯一性

“万古唯一”必须有验证机制：

- 世界记录、天象、规则反馈、历史比较、强者判断或不可伪造的后果。
- 为什么前人做不到：资源、知识、体质、时代条件、伦理选择或方法错误。
- 为什么主角能做到：多项前置条件交汇，而非“因为主角”。
- 做到后付出什么：被注视、失去退路、承担责任、产生不可逆变化。

唯一性不宜每十章重复宣传，应通过实际后果证明。

## 九、成长节奏

每个阶段安排四类回报：

1. **即时回报**：新能力可见。
2. **策略回报**：解决过去无法解决的问题。
3. **关系回报**：他人评价、联盟与敌意变化。
4. **主题回报**：主角对力量意义的理解变化。

长期避免“突破—测试—震惊—换地图”固定循环。
