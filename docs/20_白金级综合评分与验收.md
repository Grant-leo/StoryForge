# 20｜白金级综合评分与验收

## 一、评分的用途

本量表用于：

- 找到最有杠杆的短板。
- 比较多个方案或版本。
- 检查资料包能否进入细纲/写作。

它不预测真实销量，也不替代平台编辑、读者数据或作者长期执行。

## 二、一票否决

出现任一项，不得评为“白金级候选”：

1. 核心机制、角色或卷级结构与已知作品高度同构。
2. 违反用户冻结硬约束。
3. 主线依赖反派、主角或全世界持续降智。
4. 规则随剧情方便临时改变。
5. 标题简介承诺与前期内容不一致。
6. 主要角色普遍工具化，关系线无法独立推进。
7. 长篇只有重复升级和地图换皮。
8. 核心资料相互矛盾，且无状态与版本追踪。

## 三、100 分量表

### 1. 商业定位与读者承诺｜8 分

- 目标读者清楚。
- 一句话卖点可复述。
- 标题、简介、开篇、主线一致。
- 市场判断有日期、样本与来源。

### 2. 核心创意与差异化｜10 分

- 通用母题有原创实现。
- 至少三条独立差异化轴。
- 最近似作品六层审计通过。
- 创意不仅新，而且能持续产剧情。

### 3. 开篇与留存｜10 分

- 第一章有问题、选择、承诺和状态变化。
- 前三章证明核心机制与主角主动性。
- 十章内有真实回报与代价。
- 三十章内形成小闭环。

### 4. 主角驱动与成长｜8 分

- 目标明确、行动主动。
- 有优势也有不能靠力量解决的问题。
- 错误信念与终局选择清楚。
- 成长改变能力、身份、责任和认知。

### 5. 角色群像与关系网络｜10 分

- S/A 级角色有独立目标与弧线。
- 配角之间有横向关系。
- 关系包含债务、信息差、权力变化。
- 反派合理、能获得忠诚。
- 亲密关系有主体性和边界。

### 6. 欲望、稀缺与冲突引擎｜10 分

- 每个世界的欲望受环境塑造。
- 冲突即使角色聪明沟通仍成立。
- 个人、关系、制度、内心冲突相互连接。
- 事件改变后续条件。

### 7. 世界规则与成长经济｜8 分

- 核心规则有边界、验证与执行者。
- 资源循环完整。
- 金手指有成本、限制、反制和社会后果。
- 多世界不只是尺度放大。

### 8. 长篇结构与转折｜10 分

- 终局问题明确。
- 每卷有状态差、选择、高潮和余波。
- 中型弧因果完整。
- 反转由已知规则与选择产生。
- 多分辨率细纲既完整又可调整。

### 9. 爽点、情绪与节奏｜10 分

- 主爽点明确且有变体。
- 回报周期合理。
- 张力、释放、余波有层次。
- 刀、甜、敬畏、幽默服务人物。
- 不靠长期憋屈与无效虐主。

### 10. 文风与可读性｜6 分

- 声纹参数可执行。
- 多角色对白可区分。
- 信息不过载。
- 无单一作者明显模仿。
- 创作与审计分离，灵性未被模板压死。

### 11. 连载扩展与回收能力｜5 分

- 核心机制可变形。
- 旧角色可跨地图继续发挥。
- 伏笔、身份、遗产有台账。
- 未回收负债受控。
- 更新生产成本可持续。

### 12. 原创、伦理与风险控制｜5 分

- 防抄袭流程完整。
- 感情与权力关系无明显毒点。
- 市场事实不造假。
- 风险登记与修订闭环可追溯。

## 四、等级解释

| 总分 | 解释 |
|---:|---|
| 92—100 | 极强候选：可进入高强度细纲/试写；仍需真实读者验证 |
| 86—91 | 白金目标候选：核心成立，需补若干关键短板 |
| 78—85 | 强商业基础：有明显卖点，但长篇或人物仍有结构风险 |
| 68—77 | 可开发：局部亮点，尚不能直接投入长篇写作 |
| <68 | 需重构：优先修正核心承诺、角色或冲突发动机 |

必须同时满足一票否决为零。分数不应精确到虚假的小数点，除非多版本比较有一致评分人。

## 五、证据化评分

每个维度写：

```markdown
得分：7/10
置信度：中
证据：DOC-09 的冲突矩阵覆盖主角与两大势力，但卷三主要冲突仍依赖突然来敌。
扣分原因：制度冲突未转化为角色选择。
最高杠杆修复：让卷三资源审批规则迫使盟友与主角目标分裂。
```

## 六、三种视角分别打分

同一资料包至少由：

- 商业编辑视角。
- 文学/人物视角。
- 结构/连续性视角。

分别评分，再解释分歧。不要简单平均掩盖某一维度的严重问题。

## 七、进入细纲的门槛

建议：

- 核心创意、角色关系、冲突引擎、世界规则、终局均达到 70% 以上完成度。
- 无 P0。
- 开篇与第一卷达到章级。
- 全书达到剧情弧级。
- 第一卷主要角色与关系可定位到事件。
- 核心能力与资源经济闭环。

## 八、进入正文的门槛

除上项外：

- 近 30—50 章场景级细纲。
- 文风声纹已通过短样本盲审。
- 事实台账和时间线可用。
- 第一阶段伏笔与回报窗口明确。
- 写作代理只接收轻量前台提示。

用户禁止写正文时，即使达到门槛也不得擅自试写。

## 九、最终验收报告

必须包含：

1. 总分与三视角分数。
2. 一票否决检查。
3. 已完成范围。
4. 仍未完成范围。
5. 最高杠杆的三项改进。
6. 进入下一阶段的建议。
7. 已知不确定性。
8. 验证脚本结果。
