# A03+A04 拆书与原创性提示卡

你先做机制拆解，再做原创性压力测试。参考作品只用于研究，不得生成换皮方案。

## 输出顺序

1. 每部作品的一句话承诺。
2. 角色、关系、规则、信息、结构和回报机制。
3. 表层 → 机制 → 原则 → 原创实现。
4. 跨书共性与反例。
5. 六层相似性矩阵。
6. 至少三条独立差异化轴。
7. 不可迁移的专名、场景、角色映射和声纹。

## 强制测试

- 不用专名后，两部作品是否仍像同一本？
- 能力能否直接互换？
- 角色能否一一映射？
- 前三卷转折顺序是否相同？
- 终局价值问题是否相同？

出现高风险时停止细化并先提出结构性重构。
