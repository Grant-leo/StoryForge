# 00｜总原则与边界

## 一、这套方法解决的不是“点子不足”，而是“点子无法形成作品”

很多资料包的问题并非内容少，而是缺少三种连接：

1. **因果连接**：设定为什么会迫使人物行动？
2. **关系连接**：人物为什么不能各走各路，必须互相伤害、帮助、欺骗或成全？
3. **回报连接**：读者为什么愿意等待，等待后得到的是否比承诺更值？

本 Skill 的任务，是把点子变成一套能反复产出剧情的系统，而不是把百科词条写得更长。

## 二、四条总判断

### 1. 世界观是否有效

不是看地图多大、名词多炫，而是看规则能否改变人物的成本、机会和伦理选择。

判定句：

> 删除这条设定后，至少三条重要剧情或关系是否必须重写？

若答案是否定的，它可能只是装饰。

### 2. 角色是否活着

不是看角色小传多长，而是看他在主角不出现时是否仍有日程、目标、盟友、敌人和错误判断。

判定句：

> 把主角从本卷删去，这个角色接下来一周会做什么？

答不出来，角色大概率只是功能件。

### 3. 冲突是否自然

不是让双方“性格不合”，而是让他们在同一稀缺条件下无法同时实现目标。

判定句：

> 双方若都足够聪明、真诚、愿意沟通，冲突仍然存在吗？

若沟通一次即可解决，冲突通常不够坚固。

### 4. 长篇是否可持续

不是看预设了多少地图和境界，而是看每次升级是否改变：

- 主角能做什么。
- 主角需要承担什么。
- 主角与谁重新站队。
- 世界如何重新评价他。
- 过去的解决方案为何失效。

只有数字变大而结构不变，长篇迟早重复。

## 三、创作准备的三层产物

### 层 1：事实与规则层

包含：世界、资源、制度、角色、关系、能力、时间线、已确定事件。

要求：唯一 ID、状态明确、可追溯、无自相矛盾。

### 层 2：叙事发动机层

包含：欲望、稀缺、债务、信息差、权力差、选择、代价、回报、反转。

要求：能够从设定推导剧情，而不是事后替剧情找借口。

### 层 3：表达与商业层

包含：读者承诺、书名简介、开篇、节奏、声纹、情绪曲线、章节钩子。

要求：承诺与正文一致，表达服务内容，不用噱头掩盖空心。

## 四、通用而非题材专用

无论是修仙、科幻、都市、历史、悬疑、言情还是奇幻，都可以将专名抽象为以下变量：

| 专名表象 | 通用变量 |
|---|---|
| 灵石、信用点、粮票 | 可交换资源 |
| 境界、军衔、职级 | 能力与身份阶梯 |
| 宗门、公司、王朝 | 组织与制度 |
| 金手指、科技、血脉 | 非对称优势 |
| 秘境、遗迹、案件 | 高压封闭任务空间 |
| 飞升、移民、升职 | 世界层级迁移 |
| 前世、档案、记忆 | 历史身份与延迟信息 |
| 婚约、师徒、债务 | 关系合同与约束 |

设计时先处理通用变量，再回到题材表层，可显著减少换皮感。

## 五、只做准备时的边界

用户要求“不写正文”时：

允许：

- 一句话场景目的。
- 对话功能说明。
- 关键台词的语义目标或信息点。
- 不超过必要长度的微型示例，用于证明模板可执行。

禁止：

- 连续完整场景。
- 以“示例”为名大量生成正文。
- 偷偷扩写开篇试读。

## 六、质量与不确定性

所有判断分三类：

- **事实**：有来源、原文材料或 canonical 规则支持。
- **推断**：由事实推导，需说明推断链与置信度。
- **建议**：编辑性选择，可给方案与利弊，不能冒充唯一答案。

市场、平台与读者偏好会变化，任何“爆款规律”都必须带日期、样本与适用范围。

## 七、阶段冻结

推荐冻结顺序：

1. 用户硬约束与禁区。
2. 核心读者承诺与终局问题。
3. 世界底层规则、主角核心欲望、关键关系。
4. 全书卷级状态迁移。
5. 当前卷章纲。
6. 近端场景卡。

不要在底层规则未稳定时，一次性写完数千章细纲；也不要以“人物会自然生长”为理由，完全不设计终局和代价。
