# 07｜角色总谱与人物小传

## 一、人物不是标签组合

“冷艳师姐、忠诚兄弟、腹黑老板、暴躁将军”只能说明第一印象。角色真正成立需要：

- 他想要什么。
- 他为什么现在行动。
- 他愿意用什么手段。
- 他绝不愿付出什么。
- 他对自己撒了什么谎。
- 压力下他会伤害谁、保护谁、背叛谁。

标签可以作为入口，不能作为终点。

## 二、角色核心九格

每名重要角色填写：

1. **外在目标**：可观察、可失败。
2. **真实欲望**：深层需要，角色未必承认。
3. **恐惧**：最不愿再次经历什么。
4. **错误信念**：导致反复错误选择的判断。
5. **价值底线**：何事宁可失去利益也不做。
6. **能力与资源**：能实际调动什么。
7. **债务与义务**：欠谁、被谁欠、受何合同限制。
8. **秘密与盲点**：知道什么，又误解什么。
9. **弧线问题**：最终必须回答的价值问题。

## 三、角色的三层目标

```text
场景目标：这一场具体要拿到什么
阶段目标：这一卷或剧情弧要改变什么
终身目标：他以为人生最终要变成什么
```

三层目标可一致，也可冲突。人物厚度常来自：完成场景目标反而损害终身目标。

## 四、独立生命测试

对每个主要配角回答：

- 主角不存在时，他的计划是什么？
- 他最重要的关系是谁，若不是主角会更好。
- 他有何日常责任、职业压力、家庭或组织义务？
- 他在本卷获得了什么、失去了什么？
- 他是否会拒绝主角？拒绝的理由是否合理？
- 他是否曾做出主角无法代替的关键选择？

配角如果只负责提供信息、资源、赞美、背叛或恋爱，需重写。

## 五、角色功能与人格分离

先定义叙事功能，再为其设计独立人格，避免功能重复：

| 功能 | 可能的人格实现 |
|---|---|
| 指引主角 | 犹豫的旧敌、功利的交易者、犯过错的亲人 |
| 提供资源 | 债权人、竞争伙伴、制度代理人 |
| 道德镜像 | 看似反派但坚持主角不敢坚持的底线 |
| 情绪支点 | 需要主角保护，也能在关键处反向保护主角 |
| 终局见证 | 与主角价值观不同，但理解其代价的人 |

同一角色可承担多个功能，但不能每个功能都方便主角。

## 六、主角设计

主角至少需要：

- 可共情处境。
- 清晰主动性。
- 能力优势。
- 性格缺陷或认知盲点。
- 不能用力量直接解决的核心问题。
- 对成功的错误想象。
- 终局必须亲自作出的选择。

“聪明、谨慎、杀伐果断”不是完整人格。还要知道他对弱者、亲密关系、承诺、羞耻、失败和权力如何反应。

## 七、反派与对手

反派不应只比主角坏，而应：

- 有可理解的利益与世界模型。
- 在自己的信息条件下做出合理策略。
- 有真实资源、组织惯性与反制能力。
- 能赢得他人忠诚，而不全靠恐惧。
- 即使失败，其代表的结构性问题仍存在。

高级对手可分为：

- 个人对手：直接欲望冲突。
- 制度对手：规则使双方不能共存。
- 价值对手：目标相近、底线不同。
- 时间对手：寿命、灾难、窗口。
- 自我对手：主角错误信念。

## 八、角色差异化

检查主要角色是否拥有不同的：

- 句法与词汇。
- 决策速度。
- 风险偏好。
- 对权力的态度。
- 情绪防御方式。
- 解决问题的首选手段。
- 对同一规则的解释。

若把台词名字遮住仍无法辨认角色，声纹和价值观尚未成形。

## 九、人物弧不是变好

人物弧可以是：

- 成长：修正错误信念。
- 堕落：一步步合理化越界。
- 坚守：环境变化后仍守住核心价值。
- 觉醒：发现真正欲望。
- 代价：实现目标却失去更重要之物。
- 循环：重复父辈/历史错误，直到有人打破。

关键是选择与后果，而非作者宣布“他成长了”。

## 十、角色总谱的规模控制

角色数量按叙事功能与关系密度决定，而非越多越高级。建议分层：

- S 级：全书核心，完整弧线。
- A 级：多卷重要，至少一条独立弧。
- B 级：单卷关键，有目标与关系变化。
- C 级：场景功能，保持鲜明但不强行扩写。

进入新地图前先检查能否让旧角色以新身份继续发挥，避免地图一换全员报废。
