# 13｜伏笔、谜题、身份、遗产与回收

## 一、长期悬念的基本原则

悬念必须持续产生当前价值，而不是只在终局揭晓：

- 改变角色选择。
- 重塑某段关系。
- 提供局部策略优势。
- 引出新的责任或敌人。
- 让旧事件产生第二层意义。

只告诉读者“背后还有惊天秘密”，却长期没有可验证进展，会透支信任。

## 二、伏笔卡

每条伏笔记录：

| 字段 | 内容 |
|---|---|
| FO-ID | 唯一编号 |
| 表层信息 | 当时读者看到什么 |
| 真实含义 | 最终解释 |
| 首次出现 | 卷/章/事件 ID |
| 重复提示 | 不同形态的证据 |
| 误导 | 合理但错误的解释 |
| 知情者 | 谁知道多少 |
| 触发条件 | 何时可被理解 |
| 回收窗口 | 预计卷/章 |
| 回收后果 | 改变什么选择或关系 |
| 状态 | planted / reinforced / paid / retired |

## 三、公平谜题

高质量谜题应：

- 真相所需关键线索在揭晓前出现。
- 线索可以被误解，但不能根本不可见。
- 谜底解释旧异常，不只是新增设定。
- 角色的错误推理符合其信息和偏见。
- 揭晓后立即改变行动，不做纯知识展览。

## 四、身份系统

身份可分：

- 公开身份。
- 私密身份。
- 被误认身份。
- 继承身份。
- 伪造身份。
- 被制度赋予的身份。
- 未来可能成为的身份。

每个秘密身份记录：

```text
谁知道 → 有何证据 → 为什么保密 → 如何伪装
→ 哪些行为会暴露 → 暴露给不同人有何不同后果
```

身份揭示不能只制造“众人震惊”，应改变权利、义务、敌友、法律地位或亲密关系。

## 五、信物、密语与识别机制

可用作跨时空、跨组织的身份验证，但要避免低成本万能钥匙：

- 是否可伪造。
- 验证者为何相信。
- 只证明什么，不证明什么。
- 使用后会不会被追踪。
- 不同派系对同一信物是否有不同解释。
- 主角是否理解其完整含义。

高级感来自历史后果与权力关系，不来自古老辞藻。

## 六、遗产/机缘系统

遗产不只是一件宝物，可包括：

- 资源。
- 知识。
- 身份。
- 债权。
- 敌人。
- 机构。
- 未完成承诺。
- 被误解的历史。
- 可继承的责任。
- 对世界规则的漏洞或修复方案。

## 七、遗产卡的十二项

1. `LEG-ID`。
2. 留下者与历史条件。
3. 留下的真实目的。
4. 为什么不能直接交付。
5. 为何在当前阶段可触发。
6. 进入条件。
7. 守门者/竞争者。
8. 表面奖励。
9. 隐含义务或代价。
10. 对手获得后会怎样。
11. 对主线、关系、世界的影响。
12. 回收与反转计划。

## 八、分布式遗产的防机械化

大量前世、祖先或历史遗产容易变成“到新地图开宝箱”。避免方法：

- 只有部分遗产由本人主动留下，其他是误读、敌人利用、后人改造或历史自然残留。
- 有些遗产不是给主角，而是主角必须决定是否夺取。
- 有些遗产已被别人正当继承，主角没有天然所有权。
- 有些遗产互相矛盾，代表过去不同阶段的价值观。
- 获取遗产会激活债务、政治后果和身份风险。
- 遗产的真正回报可以是关系、真相或选择权，而非持续加战力。

## 九、过去强者为何不直接留下说明书

高层人物留下信息时，应考虑：

- 信息可被敌人截获、篡改或利用。
- 未来环境不可预测，固定指令可能有害。
- 他需要验证继承者的价值选择，而非只验证血脉。
- 某些真相被知道本身就会触发危险。
- 过去的自己也可能判断错误。
- 真正后手是制度、关系和约束，而非低成本遗书。

可以留下痕迹、规则、行为模式、分布式证据和只在特定选择后可理解的信号。

## 十、回收密度

每卷应：

- 回收若干旧伏笔。
- 强化少量长期谜题。
- 新增的长期债务不超过可管理规模。

建立“伏笔负债”指标：未回收长期伏笔持续增加而回报不足时，应暂停新增。

## 十一、反转的四个等级

1. 事实反转：事情不是以为的那样。
2. 动机反转：同一事实背后目的不同。
3. 关系反转：敌友与债务重新定义。
4. 价值反转：主角发现自己一直追求的答案会造成更大错误。

越高等级越依赖前期人物与规则，不应只靠隐藏信息。
