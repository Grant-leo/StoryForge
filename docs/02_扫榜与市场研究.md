# 02｜扫榜与市场研究

## 一、扫榜的目标

扫榜不是找一本书照抄，而是回答四个商业问题：

1. 目标读者现在愿意点开什么？
2. 点开后，哪些承诺能在前三十章内留住人？
3. 哪些表层元素已高度拥挤，继续使用时必须做何差异化？
4. 哪些长期结构能支撑稳定更新，而不只是开篇噱头？

## 二、必须实时检索

涉及“最新、当前、最近、榜单前几名、平台规则、热门标签”的任务必须联网，并记录：

- 平台与榜单名称。
- 抓取日期与时区。
- 排名口径。
- 页面链接或可核验来源。
- 数据缺失与访问限制。

不得用模型记忆声称某书仍在榜首。

## 三、样本设计

推荐最少 20 本，条件允许时 30—50 本，分四组：

| 组别 | 作用 | 建议占比 |
|---|---|---|
| 当前强势 | 观察当下点击语言与开篇节奏 | 35% |
| 近 30/90 天上升 | 观察新趋势而非存量大神优势 | 25% |
| 同题材常青 | 找长期稳定机制 | 25% |
| 失败/争议/掉速 | 找弃书点和伪规律 | 15% |

还应加入 2—3 本跨题材样本，用于寻找可迁移机制，避免在同质样本中自我强化。

## 四、采集字段

### 书名层

- 字数、句式、第一人称/问句/反差/身份标签。
- 是否直接暴露核心机制。
- 题材信号、情绪信号、承诺强度。
- 是否依赖平台内部梗，生命周期多长。

### 简介层

- 第一段交代谁、处境、异常。
- 核心机制出现位置。
- 冲突与代价是否明确。
- 最后一句是悬念、宣言还是卖点复述。
- 简介承诺是否在正文早期兑现。

### 开篇层

至少看第 1、3、10、20/30 章，记录：

- 第一章第一个异常或冲突何时出现。
- 主角第一次主动选择。
- 核心机制第一次展示。
- 第一次可感知回报。
- 第一名重要配角或关系钩子。
- 第一轮小闭环。
- 章末钩子的类型与重复度。

### 长期层

- 第一个大地图/身份变化。
- 第一卷终点改变了什么。
- 反派是否有独立利益。
- 核心机制在十万字后是否仍能变形。
- 更新节奏与章节长度仅作背景，不伪造未公开数据。

## 五、分析方法

### 1. 频率不是因果

“多数热门书使用某标题句式”只能说明相关，不能证明标题导致成功。还需考虑作者存量、推荐位、题材周期、更新量、质量与外部流量。

### 2. 找“稳定机制”与“短期外壳”

稳定机制示例：

- 读者能迅速理解主角的难题。
- 核心优势在早期有第一次验证。
- 每次回报同时打开更大的问题。
- 关系冲突比单纯任务更能产生连续阅读。

短期外壳示例：

- 某种流行标题词。
- 特定热梗。
- 某热门作品刚带火的同款设定。

### 3. 把观察分为三层

```markdown
观察：样本中 14/20 本在简介前两句暴露核心机制。
推断：目标读者偏好快速确认题材承诺。
建议：本项目在简介前 80 字内交代异常能力，但不解释终极来源。
置信度：中；样本受榜单与分类限制。
```

## 六、开篇机制分类

不要只统计“穿越、重生、系统”。应统计叙事功能：

- 危机先行。
- 收益先行。
- 身份反差。
- 规则异常。
- 关系债务。
- 公开羞辱或评价错位。
- 谜题先行。
- 日常破裂。
- 终局倒叙。

同一表层元素可以使用完全不同的叙事功能。

## 七、市场定位输出

最终报告必须给出：

1. 目标细分读者。
2. 一句话读者承诺。
3. 当前题材热度与拥挤度。
4. 项目与榜单样本的最近相似点。
5. 三条可迁移机制。
6. 三条必须避开的同质化表达。
7. 开篇 1/3/10/30 章功能建议。
8. 书名与简介候选生成参数。
9. 结论置信度与数据盲区。

## 八、研究伦理与版权

- 不大段复制收费正文。
- 仅记录为分析所必需的短摘录，并优先使用概括。
- 不建立可用于复刻整书的逐章剧情数据库。
- 研究产物重点是机制与统计，不是内容盗录。
